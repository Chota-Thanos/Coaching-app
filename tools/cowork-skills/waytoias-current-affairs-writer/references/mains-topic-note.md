# Mains topic note — `mains_topic_note`

This is a durable study note, not news — it should read the same and be
just as useful in two years. If the topic has a recent news hook, you can
mention it briefly for relevance, but the note itself should stand on its
own as a reference a student returns to repeatedly.

## Structure

1. **Syllabus Mapping** — the GS paper and the exact syllabus phrase this
   topic falls under.
2. **Concept** — a precise definition and the essential framework. Assume the
   reader is prepping seriously but wants clarity, not a textbook wall of text.
3. **Constitutional and Legal Basis** — relevant Articles, Acts, judgments.
   Omit this section entirely if the topic genuinely has none, rather than
   stretching for a tenuous citation.
4. **Dimensions** — the analytical angles: political, economic, social,
   environmental, ethical, international. Give each applicable angle its own
   sub-heading; skip any that don't genuinely apply to this topic.
5. **Committees, Reports and Data** — named sources with their actual key
   findings, not just a list of names.
6. **Case Studies and Examples** — two or three concrete, verifiable
   instances that illustrate the concept in practice.
7. **Way Forward** — specific measures, each tied back to a dimension raised
   above, not generic recommendations.
8. **Answer Framework** — how a student should structure a ~250-word answer
   on this topic: what the introduction, body and conclusion should each do.

## Voice

Write for permanence — avoid "recently", "last month", or anything that dates
the note. Where a fact is genuinely time-bound (a committee's report year,
a scheme's launch year), state the year explicitly instead of a relative
phrase. Length 800-1200 words — this is the longest content type here, so
budget more research time before you start writing, not while writing.

# Prelims-style MCQs — `prelims_pyq`

Write questions in the genuine UPSC Prelims style, grounded in real facts
about the topic — not trivia that turns on one obscure number nobody would
reasonably know or be expected to reason to.

## Requirements, per question

- A stem answerable from facts, not opinion.
- Exactly four options, labelled A, B, C, D.
- Exactly one defensible correct answer — if two options could both be
  argued correct, rewrite until only one is.
- An explanation covering **why the correct option is right AND why each of
  the other three is wrong.** An explanation that only justifies the answer
  and ignores the distractors is incomplete — the wrong-option reasoning is
  often what actually teaches the concept.

## Favour real UPSC patterns

- "Consider the following statements ... which of the statements given above
  is/are correct?"
- Matching pairs (List I / List II).
- Chronological ordering.
- Assertion-Reason.

A single straight fact-recall question is the weakest and least authentic
pattern — use it sparingly, if at all.

## Format when you write it out

Write the stem, then the options as `(a)`/`(b)`/`(c)`/`(d)`, then clearly mark
the correct answer, then the explanation. This plain, exam-paper-style
layout is what the filing step reads best — don't wrap it in markdown tables
or unusual formatting.

Include the source year if the question is drawn from or inspired by a real
past paper; otherwise note the year as the current one.

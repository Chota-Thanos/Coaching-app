# Match the following (List-I / List-II)

> **Status: draft.** Built from general knowledge of how UPSC/PCS papers use
> this format, not yet refined against real example questions. Treat as a
> starting point and flag for review once a real example comes in.

## Structure and components

Two parallel lists of equal length (usually 4 items each):

- **List-I**: terms, events, schemes, entities...
- **List-II**: the things they correspond to — definitions, years, features,
  ministries, authors, articles of the Constitution...

Options are different permutations of the pairing, e.g.
`(a) 1-C, 2-D, 3-A, 4-B`. Exactly one permutation is fully correct.

## Depth

Can be almost pure recall (arbitrary factual pairings — scheme ↔ launch
year) or can be elevated into rule-application if the pairing itself
reflects a classification or logic a student should understand (e.g.
matching constitutional provisions to the *type* of provision they are,
where getting it right requires understanding the category, not just
memorising a list). Prefer the latter when the source material supports it
— it's a stronger test and it's less brute-forceable by rote memorisation
of one specific list.

## Scope — selecting the lists

Both lists should be genuinely part of the same domain/topic — mismatched
lists (an item from one topic paired against a feature from an unrelated
one) make the wrong pairings implausible and the question too easy by
elimination. Good match-the-following items usually have List-II entries
that are *each individually plausible* against more than one List-I entry
at first glance — that's what makes the wrong permutations genuine
distractors rather than obviously-wrong noise.

## Skeleton

```
Match List-I with List-II and select the correct answer using the codes
given below:

List-I                          List-II
A. <item>                       1. <item>
B. <item>                       2. <item>
C. <item>                       3. <item>
D. <item>                       4. <item>

Codes:
     A   B   C   D
(a)  2   1   4   3
(b)  1   3   2   4
(c)  3   4   1   2
(d)  4   2   3   1

Answer: (x)

Explanation:
Answer is (x).

A pairs with <n> because <justification>.
B pairs with <n> because <justification>.
C pairs with <n> because <justification>.
D pairs with <n> because <justification>.
[For any pairing a student might plausibly get wrong, name the tempting
wrong pairing and why it's wrong.]

<Self-contained paragraph on the underlying topic connecting the list.>
```

## Variety reminders

- Don't let the correct permutation default to "identity" (A-1, B-2, C-3,
  D-4) or near-identity more often than chance — that's an easy tell.
- Vary which List-I/List-II item is the one most likely to be confused,
  rather than always making item D the hard one.

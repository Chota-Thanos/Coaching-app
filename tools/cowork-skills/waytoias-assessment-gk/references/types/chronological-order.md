# Chronological / sequential ordering

> **Status: draft.** Built from general knowledge of how UPSC/PCS papers use
> this format, not yet refined against real example questions. Treat as a
> starting point and flag for review once a real example comes in.

## Structure and components

- A stem naming a set of events, stages, or steps (historical events,
  stages of a process, order in which schemes/acts were introduced...).
- The items themselves, usually lettered or numbered, deliberately listed
  **out of order** in the question.
- A prompt asking for the correct chronological/sequential order.
- Options are different orderings (permutations) of the items — usually
  given as sequences of letters, e.g. `(a) II, IV, I, III`.

## Depth

Mostly factual — knowing the actual order requires knowing the actual
dates/sequence, there isn't much room for "reasoning" your way to the answer
the way assertion-reason allows. Where this format can go beyond pure
recall: choose events close enough in time, or steps subtle enough in a
process, that getting the order right requires real precision rather than
just knowing "this one is old, this one is recent." Avoid picking items so
far apart in time that the ordering is trivial regardless of specific
knowledge (e.g. one item from the 1600s next to one from 2020) — that
collapses depth back to a coin flip against odds, not real testing.

## Scope — selecting the items

Pick items from one coherent sequence (a single historical process, one
scheme's rollout stages, one institution's evolution) so the closing concept
overview can actually explain the *logic* of the sequence, not just list
dates. A sequence where the events are causally connected (each step led to
or enabled the next) makes for a stronger item than an arbitrary set of
unrelated things that merely happen to have dates.

## Skeleton

```
Consider the following events/steps:
1. <item>
2. <item>
3. <item>
4. <item>

Arrange the above in chronological/correct order:
(a) <sequence>
(b) <sequence>
(c) <sequence>
(d) <sequence>

Answer: (x)

Explanation:
Answer is (x).

<item> came first because <justification, with date/reasoning>.
<item> came next because <justification>.
... (continue through the full order)
[Where two items might plausibly be swapped, name that confusion
explicitly and explain what actually distinguishes their order.]

<Self-contained paragraph explaining why this sequence unfolded the way it
did — the logic connecting the steps, not just a date list.>
```

## Variety reminders

- Don't always place the earliest item first in the listed-but-scrambled
  order shown in the question, or always last — scramble genuinely.
- Vary how close together the items are in time/sequence across different
  questions, so the format doesn't always test the same "obviously first,
  obviously last" shortcut.

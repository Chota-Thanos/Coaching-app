# Meta-conclusion on a statement set

Confirmed from the 2026 paper — **four occurrences (Q80, Q82, Q83, Q84), all
Polity.** One of the most distinctive new shapes, and among the most
elimination-resistant in the whole paper.

## Structure and components

Statements are presented normally. What changes is the options: instead of
naming combinations of statement numbers, each option is a **second-order
claim about the statement set as a whole** — how many statements are
correct, and sometimes which.

```
Which one of the following conclusions based on the above statements is
correct?
(a) All three statements are correct.
(b) There are two correct statements, that include statement 2.
(c) There is only one correct statement.
(d) There is no correct statement.
```

The critical design feature: **options can share a count but differ on
identity** — "there are two correct statements, that include statement 2"
versus "there are two correct statements, that are statements 1 and 3". A
reader who has worked out *how many* are right still can't answer without
knowing *which*. That's what kills the usual partial-knowledge shortcuts.

## Depth

High, but not because the underlying facts are harder — because the
answering procedure is unforgiving. There is no combination to
pattern-match and nothing to eliminate by spotting one false statement: every
statement has to be settled absolutely, and then the count and the identity
both checked against each option. Partial knowledge that would earn a lucky
guess in a normal statement question earns nothing here.

## Scope — selecting the statements

Works best on material with **precise, checkable provisions** where a
statement is unambiguously right or wrong — constitutional articles,
procedural rules, committee compositions. 2026 used it exclusively on
Polity, which fits: vague or interpretive statements would make the
absolute-verdict demand feel unfair rather than rigorous.

One flourish worth knowing (2026 Q80): the statements were themselves
**negative assertions** ("There is no Article in the Constitution that
specifies…"), with the options then making meta-claims about those
negatives. Double inversion. Effective, but use sparingly — it's demanding
to write clearly and easy to make merely confusing.

## Skeleton

```
Consider the following statements with reference to <topic>:
1. <statement>
2. <statement>
3. <statement>

Which one of the following conclusions based on the above statements is
correct?
(a) All three statements are correct.
(b) There are two correct statements, that include statement <n>.
(c) There is only one correct statement.
(d) There is no correct statement.

Answer: (x)

Explanation:
Answer is (x).

Statement 1 is <correct/incorrect>. <justification>.
[If incorrect: name the trap.]
Statement 2 is ...
Statement 3 is ...

That gives <n> correct statement(s), namely <which> — which matches option
(x). [Then explicitly rule out any option sharing that count but naming a
different identity, since that is exactly where a reader loses the mark.]

<Self-contained paragraph on the underlying provisions.>
```

## Variety reminders

- Vary the true count genuinely — 2026 used all-three-correct, two-correct,
  one-correct and none-correct across its four items.
- Include at least one option pair that shares a count but differs on
  identity; without that, the format collapses into an ordinary counting
  question and loses its point.
- Rotate whether the identity constraint attaches to a correct or an
  incorrect statement.
- Because the explanation has to establish every statement absolutely, this
  format is unusually good at exposing a shaky answer key — if you can't
  settle all of them cleanly, pick different statements.
